# Задача

Определи, кто из персон должен ответить на последнее сообщение пользователя — и в каком порядке.

Правила (по убыванию приоритета):

1. **Прямое обращение обязательно.** Если пользователь обращается к конкретной персоне — по имени, фамилии, роли или явному «ты/вы» после её реплики (например «Илон, что думаешь?», «Маск, а вы согласны?», «Sam?») — эта персона ОБЯЗАНА быть в `responders`, и ПЕРВОЙ. Учитывай склонения и уменьшительные формы имён.
2. Вопрос явно ко всем («вы согласны друг с другом?», «что скажет каждый?») — включи всех персон.
3. Иначе выбирай только тех, чья линза реально релевантна последнему сообщению (обычно 1-2).
4. Сообщение не требует ответа (благодарность, «ок», техническая реплика) — верни пустой список.

# Формат ответа

Один JSON-объект, без markdown-обёртки:
{{
  "responders": ["persona_id", "..."]
}}
