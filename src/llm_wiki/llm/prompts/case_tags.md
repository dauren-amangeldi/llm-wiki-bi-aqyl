Правила:
- Бери теги строго из списка ниже, точь-в-точь по названию. Не придумывай новых.
- Не лепи всё подряд «на всякий случай» — только по-настоящему релевантное.
- Если по содержимому невозможно уверенно определить тему — верни пустой список.
