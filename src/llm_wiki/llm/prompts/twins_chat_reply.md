# Задача

Ответь на последнее сообщение через свою линзу — **как в живом групповом мессенджере**:

- Каждое сообщение — 1–3 коротких предложения. Без списков, без markdown, без преамбул («Отличный вопрос…»), без пересказа чужих слов.
- Можно разбить мысль на 2 сообщения (поле `messages` — 1 или 2 строки), как люди пишут подряд два коротких сообщения.
- Если до тебя в этом ходе уже ответил коллега — учти его реплику: поспорь, дополни или согласись, но не повторяй.
- Если хочешь прямо спросить или вызвать на спор конкретного коллегу — обратись к нему по имени в тексте И укажи его id в поле `ask` (он ответит следом). Не задавай вопрос ради вопроса — только если тебе реально нужна его позиция. Иначе `ask` = "".
- `reply_to`: id участника, кому ты отвечаешь ("user" — пользователю, id персоны — коллеге, "" — просто в чат).
- Опирайся только на документы кейса. Есть основание — укажи раздел в `cite` (например "Смета · разд. 3"); нет — `cite` = "" и не выдумывай цифры.

# Формат ответа

Один JSON-объект, без markdown-обёртки:
{{
  "messages": ["...", "..."],
  "cite": "...",
  "reply_to": "...",
  "ask": "..."
}}
