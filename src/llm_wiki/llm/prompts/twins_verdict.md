# Задача

1. Собери список открытых вопросов, на которые совет не может ответить уверенно — поле `questions` (каждый — `{{"text": "...", "persona_id": "..."}}`, где `persona_id` — кто поднял вопрос).
2. Опиши, в чём участники согласны — поле `consensus`.
3. Опиши, что осталось нерешённым, и намеренно не сглаживай это — поле `disagreement`.
4. Дай один конкретный рекомендуемый следующий шаг — поле `next_step`.
5. Определи, к какому домену ближе кейс, и верни распределение долей (сумма = 1.0) — поле `domain_distribution` с ключами `tech`, `real_estate`, `finance`.

Начинай вердикт с открытых вопросов, а не с ложной уверенности.

# Формат ответа

Один JSON-объект, без markdown-обёртки:
{{
  "questions": [{{"text": "...", "persona_id": "..."}}],
  "consensus": "...",
  "disagreement": "...",
  "next_step": "...",
  "domain_distribution": {{"tech": 0.0, "real_estate": 0.0, "finance": 0.0}}
}}
