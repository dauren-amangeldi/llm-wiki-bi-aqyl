# Выбор модели инфографики: GPT Image 2.5 Flare

Сравнение выполнено 10.09.2026 UTC (11.09.2026 Asia/Tokyo) на описании BI AQYL
из переписки: материалы → вики → кейсы → ответы и артефакты.

## Условия и результат

Рабочий `_infographic_art_director_prompt` с `gpt-5.4-mini` подготовил описание
за 8,097 с. Один неизменный результат передан всем трём моделям через OpenAI
Images API штатным CLI imagegen, без дополнения промпта. Настройки:
`1536x1024`, `quality=high`, `n=1`, PNG. Запросы последовательные.
Доступность всех моделей подтверждена списком моделей ключа проекта.

| Модель | Время изображения | Ускорение к GPT Image 2 |
| --- | ---: | ---: |
| `gpt-image-2` | 102,5 с | 1× |
| `gpt-image-2.5-flare` | 23,3 с | 4,40× |
| `gpt-image-2.5-sunburst` | 39,1 с | 2,62× |

Выбрана **Flare**: на этом примере она быстрее, сохраняет главный тезис и даёт
ясную иерархию блоков. Основная кириллица читается; вспомогательная строка под
AI-советником мелкая и малоконтрастная. Flare добавила иллюстративный вопрос чата
и теги. Sunburst создала выразительную объёмную сцену, но добавила несколько
незапрошенных слоганов, включая «Знания внутри. Решения впереди» и «Реальный
результат». Для саммари документов это менее желательно. Все три результата
сохранили основные функции продукта; качество оценивалось визуально, не вслепую.

Это **один прогон на модель**, не статистическая оценка и не гарантия ускорения.
Время CLI включает создание клиента и API-вызов с сетевой задержкой, исключает
запись PNG. Очередь Celery, структурированный JSON-вызов и подготовка промпта
в эти секунды не входят. Числовые данные, казахский язык и редактирование
изображений не проверялись. CLI не сохранил usage, стоимость не измерена.

PNG, исходный текст, промпты, логи, параметры и результаты сохранены локально

## Настройка

- Default `IMAGE_MODEL=gpt-image-2.5-flare`; явная переменная окружения имеет
  приоритет. В `.env.example` добавлены настройки модели, размера и качества.
- Размер и качество сохранены. Промпт просит 16:9, а фактический размер 3:2 —
  известное отдельное несоответствие, которое не меняли во время сравнения.
- В системном промпте убран только устаревший номер: `GPT Image 2` → `GPT Image`.
  Художественные требования сохранены; очищены устаревшие комментарии к коду.
- Для отката задать `IMAGE_MODEL=gpt-image-2` и перезапустить процессы приложения.
- Серверы и готовые артефакты этим изменением не обновляются. При выкладке проверить
  переменную `IMAGE_MODEL` и перезапустить API и воркеры, включая `worker-artifacts`.
