# UAT corrections — 14 September 2026

## Council response language

The existing routing completion now returns `response_language` (`ru`, `en`,
`kk`) alongside the selected experts. It uses the latest user question, including
an explicit request for another language. Ambiguous messages use the UI locale.
Opening rounds use the UI locale without a routing call. Every expert and handoff
in one turn receives the same resolved language. If routing fails, the existing
first-expert fallback uses the UI locale.

The response language is applied to the existing template variable and appended
as a shared system instruction. No persona or prompt Markdown files changed;
there is no extra LLM completion or translation pass. Previously saved answers
retain their original language.

Live checks with the configured `gpt-5.4-mini`, Russian persona, Russian source
and prior Russian dialogue:

- English question / Russian UI: routing resolved `en`; answer was English and
  retained `[[sharing-policy]]` citations.
- Kazakh question / English UI: routing resolved `kk`; answer was Kazakh and
  retained the citation.

These are smoke checks of language behavior, not an evaluation of answer quality.

## Knowledge contribution

`GET /api/v1/contributions?period=month|all` returns the top ten contributors and
the current user's rank/count, including when outside the top ten. It counts
existing shared cases with an identified owner, including cases without materials.
Private, anonymous and deleted cases are excluded. Ties share a rank. The month
starts at midnight on day one in `Asia/Almaty` (Astana business time).

Names come from verified `/auth/me` profiles stored in the existing `users` table.
Only first name and last initial appear in the ranking; missing names are empty
for the UI to label as a participant. Older owners acquire a display name after
their next verified login. No email or user ID is exposed in the ranking response.
There are no historical rank snapshots, so `rankDelta` is null. No migration.
